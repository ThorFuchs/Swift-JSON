# S3 initial decisions

These decisions establish the implementation boundary. Exact new public declarations
remain subject to G1 real-engine compiler/consumer qualification.

1. Prepare from an admitted JSONSchemaDocument, explicit immutable registry and
   separately recorded compilation/evaluation options. Retain the compiled plan
   for every final verdict. A public compiled-plan-only initializer would lose
   construction/reference snapshot obligations and is deferred.
2. Use a minimal package-only JSONSchema view over compiler-resolved node/resource
   identities and static edges. Existing node fields are internal. Do not make the
   whole graph public/package-mutable, import the regex runtime into the generator,
   duplicate URI resolution or infer targets from names. Dynamic construction is
   scope-aware or explicitly unsupported; native evaluation remains authoritative.
3. Reuse the existing package validation entry with the same noncopyable
   JSONWorkMeter through the entire generate invocation. Existing operation-domain
   switching preserves consumed work and terminal health. Construction, numeric
   work, references, rejected draws and completed false validations all consume
   cumulative quotas. G5 must prove this behavior; G0 typechecking alone does not.
4. Keep preparation separately bounded. The existing package compiler entry can
   borrow a preparation meter; normalized snapshot serialization and SHA-256 must
   share its owned work/retention boundary. Caller-created document/registry work
   precedes preparation. Do not add independent memory peaks or label them RSS.
5. Numeric synthesis uses bounded exact components/decimal routines. No dependency
   on the private CLI/filter targets merely to obtain arithmetic, and no Double,
   epsilon, Foundation Decimal or NSNumber authority. Any factored helper requires
   review and regression coverage without changing public arithmetic semantics.
6. Retain splitmix64-v1 wrapping arithmetic only for PRNG state/mixing. Quota
   counters use checked arithmetic. Every rejected uniform-selection draw is billed.
   The standalone reference's native vectors are preparation evidence, not a
   qualification of unmetered reference code as production runtime.
7. Specify SwiftJSON-schema-snapshot-v1 before freezing goldens: compact scalar-key
   normalized-number writer bytes, unambiguous length-prefixed resource identities,
   explicit ordering and separately identified policies/corpus. Original source
   bytes cannot be invented from a schema document/source map. No RFC8785 claim.
8. Return a certified result only through a completed native valid verdict. Keep
   searchExhausted, unsupported, sound false/not-true proofs and invalid configuration
   distinct. Propagate cancellation and operational evaluator failures terminally.
   Defaults/examples can supply candidates only; no repair or inferred requiredness.
9. Adopt the explicitly documented integer-fixture amendment and extra fractional
   negative, retaining the original packet. Python exists only in the isolated
   research/oracle environment. It never becomes a Swift runtime dependency.
10. Add one optional library product and its tests during G1; retain all current
    products and private targets. The independent Dual DSL train does not gate S3.
    Update exact CI discovery/manifest/DocC checks only alongside real additions;
    preserve all 49 core probes and unchanged pinned official suite policies.

Full generation accounting, cross-platform deterministic goldens, cancellation
behavior and support classifications remain unqualified until their gates execute.
Finite candidate search does not decide arbitrary schema satisfiability. Profiles
are preferences, with no globally minimal witness or universal generation guarantee.
