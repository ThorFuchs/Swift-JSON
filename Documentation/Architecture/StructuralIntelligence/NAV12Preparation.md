# Private prepared-entry experiment

NAV12 D0 adds a package-only preparation strategy and exclusive noncopyable
capability in JSON. Preparation owns no source authority: its mutating methods
only charge/admit profile text, compare exact strings, reserve/release logical
bytes and check/latch original health. Copyable reducer state cannot own it.
The prepared Navigation entry first creates one native read ledger, prepares,
then admits the full original document/source/map on that ledger and runs the
existing owned executor. It never nests a new reader or creates another meter.

The ordinary entry retains its original eager initializer, counters and admission
precedence. The scope has preparing/admitted/invalidated phases and the existing
one-shot source-transfer designation. Selection, path construction, completion
and transfer refuse before admission and latch failure. No source/cursor/state/
meter is returned through the preparation capability. Completion refunds source
admission only when the result does not own it; profile output reservations are
not incorrectly included in the input refund.

Full Debug/Release code generation supplements the unchanged original 2-positive/
20-negative matrix with 2 positive and 36 ordinary-negative prepared-capability
outcomes. A compiler crash, permitted escape or incidental diagnostic blocks this
experiment. Runtime tests require every-counter no-op parity, one root admission,
cumulative work/exact/one-below quotas, pre-admission refusal, caught-error and
inner-text cancellation priority, one-shot transfer, teardown and independent
concurrent invocations. Logical reservations are not heap/RSS bounds.

Run `python3 Scripts/ci.py --lane store-preparation` for source-bound receipts.
The lane requires all ten named Swift Testing identities, Release ASan, targeted
TSan, strict-memory compilation and both compiler matrices. Native/Linux retain
the original gates and add the prepared matrix; all 49 core-cap witnesses and
126 maintenance identities remain mandatory. Actual receipts, not this contract,
establish execution. No public declaration/product, store-follow engine, merge
or release is introduced by this preparation increment.
