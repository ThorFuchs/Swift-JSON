# 1.7.0 candidate qualification contract

**Release candidate; unpublished.** Source version 1.7.0 identifies this candidate,
not a published tag. Latest stable remains 1.6.1. Exact candidate commit/tree,
command receipts, environment and final outcomes belong to the target-bound review
dossier and proposed public qualification assets. This contract does not preclaim
CI success. Merge, tag, release and manual documentation deployment require separate
authorization. Exact-version resolution and independent public downloads follow an
authorized publication; path/revision consumers cannot prove a nonexistent tag.

## Inventory and semantic authority

Ten opt-in libraries: JSON, JSONSchema, JSONSchemaExamples, JSONStreaming, JSONPatch,
JSONHTML, JSONBridges, JSONNavigation, JSONInspection and JSONTransform; plus the
swift-json executable. Ten DocC catalogs, 1,214 authored declarations (Inspection95,
Navigation56, Transform42); synthesized declarations are excluded. Root dependencies
remain empty. Regex, filter runtime and CLI engine remain package-private. Original
Apache-2.0 and retained notices/pins apply. Swift6.4+, language6, macOS/iOS27 minima
are unchanged. No new dialect, resolver, fallback, E11/E12 or lower deployment floor.

JSON owns exact decimals/scalar identity and admission. The accepted Transform engine
uses one private compiler/VM. Public scopes own one finite cumulative execution
ledger; the CLI borrows its existing job ledger through package-only adapters.
Escaped handles invalidate, terminal failure latches, output aliases release and
native output admission precedes publication. Caller callback/comparison work is
not an owned instruction quota; logical retention is not RSS or allocation totals.
