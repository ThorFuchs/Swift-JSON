Twenty new Swift Testing functions in JSONIntegrationTests use only the four
public products. They combine strict parsing, scoped native projection and
presence, offline schema plans, Patch/Merge Patch, exact Version 1 payloads,
awaited writing and strict reparsing. Independent golden bytes, ordered scalar
keys and integer oracles supplement round trips. Consumer-owned accounts carry
successful cumulative reports; failure/cancellation latches termination without
inventing failed-work accounting or retrying with a full allowance.

Caller-owned staged root-array and NDJSON import tests keep provisional accepted
values separate from publication. Malformed tails, record exhaustion, source
failure and cancellation prevent commit and stop further pulls. Sink refusal and
cancellation preserve accepted bytes, including cancellation immediately after
accepting the final full output chunk. These tests add no library persistence or
transport semantics.

## Discovered defect and assertion gaps

Removing an entire native resource bundle exposed a fatal error in SwiftPM's
generated Bundle.module accessor. The library now searches a finite set of
standard installed locations without trapping and throws structured metaSchema
failure. All nine resource integrity pins remain enforced. A separate public
consumer verifies intact loading, entire-bundle absence and same-size valid-JSON
corruption, restoring every byte afterward. Observed native resources use
Contents/Resources plus Contents/Info.plist; both Linux architectures use flat
Draft2020-12 plus Info.plist. Exact file membership is enforced.

The [single-site pilot](MutationPilot.json) first killed 22 of 24 mutants. M17
survived because later allocations masked the missing post-await cancellation
checkpoint; a one-byte final full chunk minimizes that gap. M20 survived because
the failed child itself had no successful evaluated locations; a failed parent
with successfully evaluated children exposes erroneous annotation merging.
Both regressions pass on normal code and kill their mutants. The complete repeat
kills all 24; two private regex anchor/aggregate-budget mutants bring the pilot
to 26 behavioral kills. Zero survivors, equivalents, unbuildable cases, timeouts
or execution errors remain. This bounded pilot does not prove exhaustive correctness.
