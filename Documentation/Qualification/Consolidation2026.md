# Development consolidation qualification

This source is unreleased **1.7.0-dev**. Stable **1.6.1** and its assets remain
unchanged. Integration, qualification and publication are separate facts; neither
a source version nor a merged pull request publishes a version.

The consolidation combines the admitted set/matrix source with the previously
reviewed graph, JSONTransform and optional authored DSL proposals. It introduces
no new interpretation of JSON, schema validation, graph identity or query syntax.
The component implementations retain their source-bound predecessor records;
those records do not qualify a changed combined tree.

## Inventory and ownership

There are twelve library products plus `swift-json`: JSON, JSONSchema,
JSONSchemaExamples, JSONStreaming, JSONPatch, JSONHTML, JSONBridges,
JSONNavigation, JSONInspection, JSONTransform, JSONValueDSL and JSONSchemaDSL.
JSONDSLCore supplies shared public generic structure but has no selectable
library product. Its reference makes thirteen DocC catalogs. Derive declaration
counts from actual compiler graphs, excluding synthesis and extension containers.
Root dependencies remain empty. Swift tools/compiler 6.4+, language mode 6 and
macOS/iOS 27 minima remain unchanged.

JSON retains exact bounded decimals, scalar identity, strict syntax and checked
admission. Schema DSL emits ordinary JSONSchemaDocument; native compilation and
validation own semantics. DSL callbacks/staging are trusted caller work, followed
by separately bounded cumulative finalization. There is no whole-DSL staging,
instruction or RSS guarantee. Transform retains one private compiler/VM and one
invocation context; the CLI borrows its existing job ledger. Graph queries use
the documented independent complete-source admissions. These operation boundaries
are explicit; a caller pipeline is not silently promised one global budget.
