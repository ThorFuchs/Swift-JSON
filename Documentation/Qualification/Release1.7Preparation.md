# 1.7.0 combined release preparation

This contract records preparation of the combined twelve-library1.7.0 source,
not historical RC6fe8067. At preparation, latest stable remains1.6.1. Final source
identity, gate outcomes and performance decisions belong to the qualification
receipt; publication is established by the official release. Preparing a candidate
does not authorize a protected merge, tag or GitHub release publication.

## Candidate scope

The release includes JSON, JSONSchema, JSONSchemaExamples, JSONStreaming,
JSONPatch, JSONHTML, JSONBridges, JSONNavigation, JSONInspection, JSONTransform,
JSONValueDSL, JSONSchemaDSL and swift-json. JSONDSLCore is a shared public module
without a product. Root dependencies remain empty. Preserve Swift 6.4+/language 6,
macOS/iOS 27 minima, Apache-2.0 and all upstream notices.

Navigation 56, Inspection 162, Transform 42 and the total 1,500 authored declarations
are the current reviewed baseline. No new store/follow, batches, persistence,
query grammar, resolver, platform or public API is added during preparation.
Store construction/preparation stays package-only. All existing operation, source
identity, error, cancellation, concurrency and finite-budget contracts remain.

## Shared source ownership

Use one final-source candidate. Navigation/Inspection preparation owns the common
freeze ledger, version/CLI identity, release envelope and combined qualification
binding. Transform review owns API/lifecycle/accounting/shared-kernel findings,
its targeted documentation and the scoped performance evidence/disposition
proposal. Integrate only reviewed focused commits, never whole obsolete drafts.
Do not edit shared main or rewrite the frozen RC.

## Performance and platform limits

Navigation G4 remains HOLD, with zero accepted controlled timing samples.
The original Transform P4 waiver applies to its historical scoped candidate;
later 44/150 and 119/150 windows remain separate partial populations with the
original incomplete-output incident retained. Neither is a new candidate's
allocation/overhead pass. Record any final-source scope mapping and decision
explicitly under the unchanged 10% review trigger. Logical retained bytes are
not process RSS or heap allocation totals; caller work is not an owned instruction
quota. Do not benchmark a busy host or manufacture measurements.

Retain the historical approximately 11% streaming disposition. Do not broaden
mobile/device, full-root WasmKit, WASI sanitizer, CLI/file-I/O, browser, Embedded
Swift or lower-deployment claims beyond actual source-bound evidence. The physical
iPad deferral remains explicit; simulator output is not physical-device evidence.

## Assets and publication boundary

The private working ledger may contain local paths, approvals, raw crash traces
and provider archives. None belongs in public release assets. Publishable assets
need a public-safe receipt with actual commands, source/fixture/toolchain pins,
counts and limitations. Verify every archive/checksum byte before upload.

A path/revision consumer does not prove a nonexistent 1.7.0 version tag. Actual tag
resolution, asset downloads, released DocC and Swift Package Index checks follow
separately authorized tag/publication. Stable1.6.1 remains unchanged throughout.
