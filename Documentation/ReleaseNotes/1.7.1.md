# Swift-JSON 1.7.1 — release notes

This patch fixes JSONSchema resource discovery in SwiftPM's native test host.
Preparation and tagging do not establish publication; the official GitHub release
and its qualification asset identify the final source and actual outcomes.

## Fixed

When the native SwiftPM backend uses `swiftpm-testing-helper` as the main bundle,
JSONSchema can be loaded from a nested XCTest bundle while its resource bundle
is installed beside that bundle. The loader now includes this fixed sibling
location, after the existing candidates, on Objective-C-capable Apple platforms.
All nine packaged Draft 2020-12 resources retain their exact size and SHA-256
checks. A selected missing or corrupt resource remains an operational failure;
there is no permissive fallback, online resolution or new cache.

A public Swift Testing consumer exercises this host layout in Debug and Release
without environment overrides, including valid and invalid exact integers above
2^53. Existing standalone intact, missing and corrupt resource checks remain.
CLI metadata reports `1.7.1` with the deterministic final-source identity.
