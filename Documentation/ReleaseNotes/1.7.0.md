# Swift-JSON 1.7.0 — release notes

These notes describe the combined1.7.0 source. They do not establish publication;
consult the official release and its source-bound qualification asset. The
[release checklist](../Qualification/Release1.7Preparation.md) defines the gates.

## Included capabilities

- Add JSONInspection as an opt-in library: factual complete/prefix array evidence,
  source-attached structural snapshots, checked trees/sparse object tables,
  first-occurrence exact structural sets, exact numeric matrix orientation and
  source-bound directed graphs with bounded complete BFS.
- Add JSONTransform over the existing shared compiler/pull VM, with guarded
  invocation-owned execution, exact native output and cumulative CLI accounting.
- Add JSONValueDSL and JSONSchemaDSL for trusted authored values/schema documents.
  Finite checked finalization uses existing exact values and native schema
  compilation/validation; authored staging/callbacks remain caller work.
- Retain every existing core/schema/example/stream/Patch/HTML/bridge/Navigation
  product and the CLI. Twelve libraries plus CLI share the release version;
  JSONDSLCore provides shared public generic structure without its own product.

## Compatibility and scope

The public API is additive to stable 1.6.1. Exact bounded decimals, decoded scalar
identity, ordered object storage/order-independent equality, strict UTF-8, offline
immutable schema plans, operation budgets and source-map coherence remain binding.
Default profiles remain finite. Construction and each separately reported read
retain their documented admission boundaries; caller pipelines are not implicitly
one ledger. Missing, explicit null, typed shape failures, operational exhaustion
and cancellation remain distinct.

Apple baselines remain tools/compiler 6.4+, language 6 and macOS/iOS/iPadOS 27+.
Linux and WASI claims retain their qualified architecture/runtime/host scopes.
The final receipt must state actual supported-lane outcomes rather than deriving
mobile runtime, full CLI/WASI, browser or sanitizer guarantees from compilation.
No runtime package dependencies or new backend are introduced.

Private configured-store preparation/construction remains internal to the package.
Public store/follow, NAV13 aggregate access, persistence, retrieval and text-sequence
framing are not part of this release. No matrix arithmetic, graph serializer or
alternative JSON/query semantic authority is added.

## Qualification and known limits

Final-source Native/Linux/safety/ownership/consumer/DocC/archive and scoped portable
receipts are required before release. Independent suite policy exclusions are
separate from evaluated successes. Swift Build planner incidents and successful
unchanged-source retries remain visible; no unconfirmed toolchain fix is claimed.

Controlled Navigation performance remains HOLD. Transform's historical scoped
P4 waiver and later partial sampling windows are not an allocation pass. The
final-source performance disposition belongs to the qualification receipt; no
speed/throughput/allocation-
efficiency/RSS claim is made. Logical accounting is not physical memory.
The existing streaming regression disposition and 10% review trigger are unchanged.

Final source, public qualification, compiled documentation and checksum assets
will be attached only after their actual byte/source checks and the maintainer's
separate release actions. See [the roadmap](../ReleaseRoadmap.md) for later waves.
