## 1.0.0 — 2026-10-11

First stable release.

- Public GitHub Pages documentation with four native DocC references; the exact
  artifact publishes from `main` after native, safety and documentation CI pass.
- Public README with eight executed Swift examples; complete authored API/parameter
  documentation, focused DocC guides and verified native-symbol DocC catalogs.

- Four SwiftPM library products on Swift 6.4, Swift 6 and macOS 27: JSON,
  JSONSchema, JSONStreaming and JSONPatch. No root package dependencies.
- Exact bounded decimal mathematics and decoded-scalar key/text identity;
  ordered objects with order-independent equality and hashing.
- One strict incremental UTF-8 parser and writer; native value-based Codable,
  presence/construction helpers, RFC 6901 Pointer, owned source documents,
  bounded previews/diagnostics and versioned operation reports.
- Draft 2020-12 compilation/evaluation with explicit immutable registries,
  packaged meta-schema bootstrap, vocabularies, static/dynamic references,
  successful-branch annotations, unevaluated behavior, native formats,
  flag/basic output and raw declaration inspection.
- Private interruptible, budgeted ECMA-262 2020 Unicode regex implementation;
  pinned Unicode 13 tables and plan-local immutable program sharing.
- Staged RFC 6902 and RFC 7396, including root removal and intermediate limits.
- Pull event/value streams, strict NDJSON, root-array provisional elements and
  explicit completion, awaited sinks, backpressure and cumulative quotas.
- Pinned independent syntax/schema suites with enumerated policy outcomes,
  deterministic malformed replay, native concurrency/safety lanes, public
  qualification and benchmark tools, compiled examples and four DocC catalogs.

Qualification details and counts are in Documentation/Qualification/README.md. Resource
policy bounds logical work/ownership; it is not an operating-system RSS ceiling.

remain unselected; projection and RFC 7464 framing remain deferred.
