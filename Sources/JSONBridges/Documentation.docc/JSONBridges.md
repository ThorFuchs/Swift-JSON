# ``JSONBridges``

Opt-in native conversions with explicit mathematical fidelity and finite admission.

This module depends only on JSON. Import both modules explicitly; there is no
re-export, automatic core conformance or Foundation serialization authority.
All five methods delegate to existing JSONNumber operations. Original code is
Apache-2.0; no new upstream adaptation or external dependency is introduced.
